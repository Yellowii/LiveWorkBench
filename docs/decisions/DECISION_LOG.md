## 变更流程

模块对话提出具体旧/新输入输出、影响范围、兼容方式和验证证据 → 主架构/集成负责人审核 → 同步权威架构/契约/本表/STATUS → 分支或 worktree 实施 → 回归后统一合并。

未审查的提案保留为提案，不先改公共 API 或其他模块。负责人身份与任务分配待用户明确；本次没有自行任命或创建开发对话。
